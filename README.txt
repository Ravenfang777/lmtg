KH1FM REDESIGNED FIVE-SLOT LIMIT GAUGE v2.1
Half-scale native-geometry OpenKH edition

TARGET
  Kingdom Hearts Final Mix, Steam Global 1.0.0.2
  LuaBackendHook v1.9.1-hook / LuaEngine v5.0
  LIMIT System v1.6

WHAT CHANGED FROM v2
  - Rebuilt the slot coordinates from the two supplied redesigned images.
  - Uses straight vertical slots and their exact stepped black backing.
  - Uses the redesigned fifth-slot lower-right cutout.
  - Uses dark-to-bright red and gray shading bands.
  - Moves the red LIMIT label to the redesigned position.
  - Defaults to approximately half the prior size.

LIMIT BEHAVIOR
    0-19 LIMIT = all five redesigned empty slots
   20-39 LIMIT = slot 1 filled
   40-59 LIMIT = slots 1-2 filled
   60-79 LIMIT = slots 1-3 filled
   80-99 LIMIT = slots 1-4 filled
     100 LIMIT = slots 1-5 filled

SIZE AND POSITION
  Open:
    scripts/ZZZ_KH1FM_LIMIT_Gauge_v2_1_RedesignedHalfScale.lua

  Edit only:
    ORIGIN = {
        X = 0,
        Y = 0,
        SCALE = 0.50,
    }

  X moves the complete layout horizontally.
  Y moves the complete layout vertically.
  SCALE resizes the label and all five slots together.

  Suggested SCALE values:
    0.40 = smaller
    0.50 = default half size
    0.60 = slightly larger
    1.00 = redesigned source size

  The default visible footprint is approximately 112 x 30 native HUD pixels.

REFERENCE AND PREVIEW IMAGES
  Reference_Design_LIMIT_0.png and Reference_Design_LIMIT_100.png are the
  supplied redesigned images.

  Preview_LIMIT_0_DefaultScale_0_50.png and
  Preview_LIMIT_100_DefaultScale_0_50.png show the geometry generated by the
  default Lua settings.

  The runtime renderer uses native HUD geometry, not PNG or DDS sampling.
  Four solid shading bands approximate each source image's smooth gradient.

INSTALL
  1. Disable/remove KH1FM Adjustable Five-Slot LIMIT Gauge v2.
  2. Disable every older Numeric, Graphic, Texture, and Resource Probe Sora
     HUD controller.
  3. Keep ZZZ_KH1FM_LIMIT_System_v1_6_EnemyBoundsOrder.lua enabled.
  4. Enemy HP HUD v4.1 may remain enabled.
  5. Add this ZIP as a Kingdom Hearts 1 mod in OpenKH Mod Manager.
  6. Enable it, then use Build and Run.
  7. Completely close and restart KH1FM. Do not switch from v2 with F1.
